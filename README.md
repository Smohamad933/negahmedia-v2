# نگاه مدیا — وب‌سایت + پنل مدیریت محتوا

سایت رسمی **آژانس خلاق و تبلیغاتی نگاه مدیا** به‌همراه پنل مدیریت محتوای اختصاصی.
نوشته‌شده با **PHP خالص** و بدون هیچ کتابخانه یا فریم‌ورک بیرونی؛ روی هر هاست معمولی (cPanel، DirectAdmin یا سرور اختصاصی) اجرا می‌شود.

## امکانات

### سایت

**سربرگ بدون منو:** هدر سایت فقط دو چیز دارد — لوگوتایپ برند (آیکون + نام) و بلوک شماره تماس.
هیچ منوی ناوبری، دکمه همبرگری یا فهرست لینکی وجود ندارد.

| بخش | توضیح |
|---|---|
| هیرو | تیتر اصلی با ورود کلمه‌به‌کلمه، متن معرفی، شعار فرعی و دو دکمه اقدام |
| نوار چرخان | نمایش چرخشی حوزه‌های تخصصی |
| برندها و همراهان | نوار متحرک لوگوهای **ویژه** + دکمه رفتن به صفحه کامل همراهان |
| نوار بزرگ | دو ردیف متن درشت متحرک در جهت مخالف (متن آن از پنل قابل تغییر است) |
| خدمات | ۶ خدمت در فهرست شماره‌دار با افکت هاور |
| درباره نگاه و آمار | مانیفست + ۳ آمار کلیدی با **شمارش عددی** هنگام دیدن |
| مراحل همکاری | شناخت، استراتژی، خلق، اجرا — با خط پیشرفت متصل‌شونده |
| نمونه‌کارها | فقط زمانی نمایش داده می‌شود که نمونه‌کاری ثبت شده باشد |
| تماس | فرم درخواست پروژه با اعتبارسنجی و ضداسپم |
| صفحه همراهان | فهرست کامل همه برندها و نهادها، دسته‌بندی‌شده با ناوبری سریع |
| صفحه اختصاصی برند | برای هر همراه یک صفحه مستقل با معرفی، تصویر کاور، لینک وب‌سایت و گالری کارهای انجام‌شده |
| پاصفحه | لوگوتایپ برند، اطلاعات تماس و شبکه‌های اجتماعی (بدون منو) |

### پنل مدیریت

- داشبورد آماری با وضعیت سیستم، آخرین پیام‌ها و **آمار واقعی بازدید سایت**
- ویرایش **همه** متن‌های سایت از پنل (بدون دست زدن به کد)
- **آپلود فونت اختصاصی** برای متن و تیترها، یا اتصال به CSS فونت بیرونی
- **رنگ تأکیدی قابل تغییر** — روشن و تیره‌اش خودکار ساخته می‌شود
- **کادر CSS سفارشی** برای اعمال تغییرات ظاهری دلخواه
- مدیریت برندها در سه دسته: افزودن، ویرایش، جابه‌جایی ترتیب، پنهان‌سازی و حذف
- مدیریت لوگو با **دو روش**: آپلود فایل تصویری یا وارد کردن آدرس تصویر
- **انتخاب برندهای ویژه** برای صفحه اصلی با یک کلیک (★)
- مدیریت خدمات، آمار کلیدی و مراحل همکاری
- مدیریت نمونه‌کارها با تصویر، دسته‌بندی و لینک
- **صفحه اختصاصی برای هر برند** با متن معرفی و تصویر کاور
- **گالری مستقل برای هر برند**: افزودن چندین کار یا محتوای تصویری با عنوان، دسته، توضیح و لینک
- کلید خاموش/روشن کردن انیمیشن‌های سایت
- صندوق پیام‌های دریافتی از فرم تماس
- مدیریت چند کاربر با دو نقش (مدیر کل / ویرایشگر)
- پشتیبان‌گیری: دانلود سورس کامل به‌صورت ZIP و پشتیبان دیتابیس

├── install.php                نصب‌کننده (بعد از نصب حذف شود)
├── .htaccess                  تنظیمات آپاچی: فشرده‌سازی، کش، امنیت
├── robots.txt
├── includes/
│   ├── config.php             پیکربندی (دیتابیس، آدرس پایه)
│   ├── db.php                 لایه دیتابیس PDO — MySQL و SQLite
│   ├── functions.php          توابع کمکی، امنیتی، آپلود و رنگ
│   ├── schema.php             ساختار جداول + به‌روزرسانی خودکار ساختار
│   ├── seed.php               داده‌های پیش‌فرض
│   ├── bootstrap.php          راه‌انداز مشترک

│   └── .htaccess              مسدودسازی دسترسی مستقیم
├── admin/
│   ├── login.php / logout.php
│   ├── index.php              داشبورد
│   ├── settings.php           متن‌ها، هیرو و اطلاعات تماس
│   ├── appearance.php         فونت اختصاصی، رنگ، CSS سفارشی، انیمیشن
│   ├── clients.php            برندها، لوگوها و انتخاب موارد ویژه
│   ├── gallery.php            صفحه اختصاصی و گالری هر برند
│   ├── content.php            خدمات، آمار، مراحل همکاری
│   ├── projects.php           نمونه‌کارها
│   ├── messages.php           پیام‌های دریافتی
│   ├── users.php              کاربران پنل
│   ├── backup.php             پشتیبان‌گیری
│   └── inc/auth.php           احراز هویت و قالب پنل
├── assets/
│   ├── css/style.css          استایل پایه سایت
│   ├── css/theme.php          استایل پویا: فونت، رنگ و CSS سفارشی
│   ├── css/admin.css          استایل پنل
│   ├── js/app.js / admin.js
│   ├── favicon.svg
│   └── fonts/                 فونت وزیرمتن (میزبانی محلی)
├── uploads/
│   ├── logos/                 لوگوی کارفرماها
│   ├── projects/              تصاویر نمونه‌کارهای عمومی

│   ├── gallery/               تصاویر گالری برندها
│   ├── fonts/                 فونت‌های اختصاصی آپلودشده

> شما را به خروجی `style.css` اضافه می‌کند. پس از هر تغییر در پنل، نسخه کش آن خودکار عوض می‌شود.

## نصب روی هاست

### گام ۱ — آپلود فایل‌ها

همه فایل‌ها و پوشه‌ها را با **همین ساختار** در `public_html` (یا پوشه دامنه) آپلود کنید.
مطمئن شوید پوشه‌های `uploads`، `uploads/logos`، `uploads/projects`، `uploads/clients`، `uploads/gallery`، `uploads/fonts` و `data`
وجود دارند و **قابل نوشتن (755 یا 775)** هستند.

### گام ۲ — ساخت دیتابیس (فقط برای MySQL)

اگر می‌خواهید از MySQL استفاده کنید، در cPanel → **MySQL Databases** یک دیتابیس بسازید:

- کاراکترست: `utf8mb4`
- Collation: `utf8mb4_unicode_ci`
- یک کاربر بسازید و به دیتابیس **ALL PRIVILEGES** بدهید

> اگر نمی‌خواهید درگیر دیتابیس شوید، همین مرحله را رد کنید؛ نصب‌کننده به‌صورت پیش‌فرض از **SQLite** استفاده می‌کند و همه چیز خودکار ساخته می‌شود.

### گام ۳ — اجرای نصب‌کننده

آدرس زیر را در مرورگر باز کنید:

```
https://your-domain.com/install.php
```

اطلاعات خواسته‌شده را وارد کنید:

1. **حساب مدیر:** نام کاربری لاتین، رمز عبور حداقل ۸ نویسه، نام و ایمیل
2. **اطلاعات سایت:** نام مجموعه و آدرس پایه
   - ریشه دامنه → `/`
   - داخل پوشه → `/negah/`
3. **دیتابیس:** SQLite (پیش‌فرض) یا MySQL + مشخصات اتصال

پس از زدن «شروع نصب»، جداول ساخته و همه محتوای پیش‌فرض (۳ دسته، ۳۱ برند، ۶ خدمت، ۴ مرحله، ۳ آمار و متن‌ها) خودکار درج می‌شود.

### گام ۴ — حذف نصب‌کننده

> ⚠️ **مهم:** فایل `install.php` را از هاست حذف کنید.

### گام ۵ — تنظیمات نهایی

اگر سایت داخل پوشه است، مقدار `base_url` را در `includes/config.php` بررسی کنید. سپس در پنل مدیریت وارد شوید و متن‌ها و لوگوها را تنظیم کنید.

## ورود به پنل مدیریت

```
https://your-domain.com/admin/login.php
```

با نام کاربری و رمزی که در مرحله نصب ساختید وارد شوید.
دسترسی به پنل با `noindex, nofollow` از موتورهای جستجو پنهان شده و پس از **۵ تلاش ناموفق**، ورود به مدت ۵ دقیقه قفل می‌شود.

### راهنمای بخش‌های پنل

| بخش | کاربرد |
|---|---|
| **داشبورد** | آمار کلی، بازدید روزانه/هفتگی/کل سایت، نمودار ۳۰ روزه، آخرین پیام‌ها و وضعیت سیستم |
| **متن‌ها و تماس** | تیتر هیرو، متن معرفی، مانیفست، شماره تماس، ایمیل، شبکه‌های اجتماعی |
| **ظاهر، فونت و CSS** | آپلود فونت اختصاصی، رنگ تأکیدی، CSS سفارشی، انیمیشن، برچسب شماره تماس، تنظیمات صفحه همراهان |
| **برندها و لوگوها** | مدیریت سه دسته و همه همراهان + ثبت لوگو + انتخاب موارد ویژه |
| **گالری برندها** | انتخاب هر برند، نوشتن معرفی، ثبت کاور و افزودن/مرتب‌سازی کارهای گالری |
| **خدمات، آمار و مراحل** | ویرایش سه بخش محتوایی سایت با ترتیب دلخواه |
| **نمونه‌کارها** | افزودن پروژه با تصویر، دسته و لینک |
| **پیام‌های دریافتی** | مشاهده، علامت‌گذاری و حذف پیام‌های فرم تماس |
| **کاربران پنل** | افزودن کاربر با نقش مدیر کل یا ویرایشگر |
| **پشتیبان‌گیری** | دانلود سورس کامل (ZIP) و دریافت پشتیبان دیتابیس |

## مدیریت لوگوی کارفرماها

در پنل → **برندها و لوگوها**، برای هر مجموعه دو راه دارید:

### روش اول — آپلود فایل

فایل لوگو را از سیستم خود انتخاب کنید.

- فرمت‌های مجاز: **PNG، JPG، WEBP، GIF، SVG**
- حداکثر حجم: **۲ مگابایت**
- پیشنهاد: تصویر با **پس‌زمینه شفاف** و عرض حدود **۴۰۰ پیکسل**
- نوع فایل، حجم و سالم بودن تصویر به‌صورت خودکار بررسی می‌شود

### روش دوم — آدرس تصویر

اگر لوگو روی سرور یا فضای ابری شماست، آدرس کامل آن را وارد کنید (با `http` یا `https`).

> اگر هر دو را وارد کنید، **فایل آپلودی اولویت دارد.**

### نکات نمایشی

- لوگوها در دیواری با خطوط مویی و اندازه یکسان نمایش داده می‌شوند
- تا زمانی که لوگویی ثبت نشده باشد، **نام برند با تایپوگرافی فارسی** نشان داده می‌شود؛ بنابراین سایت از روز اول کامل به نظر می‌رسد
- لوگوها به‌صورت سیاه‌وسفید (grayscale) نمایش داده می‌شوند و با هاور، رنگی و کمی بزرگ‌تر می‌شوند — برای هماهنگی بصری بهتر
- با دکمه‌های **↑ ↓** ترتیب نمایش هر برند را تغییر دهید
- فیلد **وب‌سایت** برای هر برند اختیاری است؛ اگر پر شود، در صفحه اختصاصی برند دکمه «وب‌سایت برند» نمایش داده می‌شود
- کلیک روی هر لوگو یا نام برند، به صفحه اختصاصی همان برند می‌رود

### ویژگی جابه‌جایی

برای جابه‌جایی گروهی و سریع، در جدول هر دسته، دکمه‌های جهتنما نمایش داده می‌شود.

## نمایش برندها در صفحه اصلی و صفحه همراهان

با ۳۱ برند، نمایش همه لوگوها در صفحه اصلی می‌تواند شلوغ شود. به همین دلیل دو حالت دارید:

### حالت ۱ — انتخاب دستی موارد ویژه (پیش‌فرض)

در پنل → **برندها و لوگوها**:

- کنار هر برند دکمه **★** هست؛ با یک کلیک آن برند به صفحه اصلی اضافه یا از آن برداشته می‌شود
- برای انتخاب سریع یک دسته کامل: **★ همه ویژه** یا **☆ هیچ‌کدام** در سربرگ همان دسته
- در فرم ویرایش هر برند هم گزینه «نمایش در صفحه اصلی (ویژه)» وجود دارد

صفحه اصلی فقط موارد ویژه را در **نوار متحرک لوگو** نشان می‌دهد و زیرش دکمه
**«دیدن همه همراهان»** قرار دارد که به صفحه کامل همراهان می‌رود.

### حالت ۲ — اولین موارد فهرست

اگر انتخاب دستی نمی‌خواهید، در پنل → **ظاهر، فونت و CSS** حالت را روی
«اولین موارد فهرست» بگذارید تا بر اساس ترتیب، چند برند اول نمایش داده شود.

### صفحه کامل همراهان

آدرس این صفحه: `your-domain.com/clients.php`

- همه برندها، دسته‌بندی‌شده در سه بخش
- ناوبری سریع (چیپس‌های دسته) برای پرش بین بخش‌ها
- شمارش کل مجموعه‌ها و حوزه‌های همکاری در سرصفحه
- فراخوان اقدام در پایان صفحه

> **نکته:** اگر هیچ برندی «ویژه» نشده باشد، به‌صورت خودکار اولین موارد نمایش داده می‌شود —
> پس صفحه اصلی هرگز خالی نمی‌ماند.

### تنظیمات مرتبط

در پنل → **ظاهر، فونت و CSS**:

| تنظیم | کاربرد |
|---|---|
| حالت نمایش | انتخاب دستی یا اولین موارد فهرست |
| حداکثر تعداد | چند برند در صفحه اصلی دیده شود (۰ = پنهان کردن بخش) |
| متن دکمه «دیدن همه» | مثلاً «مشاهده همه برندها» |
| عنوان و توضیح صفحه همراهان | متن سرصفحه `clients.php` |

## آمار بازدید سایت

در داشبورد پنل، بخش **بازدید سایت** به‌صورت خودکار بازدید صفحات عمومی را ثبت می‌کند و این موارد را نشان می‌دهد:

- تعداد کل بازدید صفحات
- بازدید امروز
- مجموع بازدید هفت روز اخیر
- تعداد تقریبی بازدیدکننده‌ها بر اساس کوکی امن
- نمودار روزانه ۳۰ روز اخیر و فهرست صفحات پربازدید

بازدید پنل مدیریت، فایل‌های CSS/JS و ربات‌های شناخته‌شده در آمار محاسبه نمی‌شوند. برای حفظ حریم خصوصی، IP ذخیره نمی‌شود و فقط یک شناسه هش‌شده برای محاسبه بازدیدکننده تقریبی نگه‌داری می‌شود.

## صفحه اختصاصی و گالری هر برند

هر کارت برند در صفحه اصلی و صفحه `clients.php` به صفحه مستقل همان برند لینک می‌شود:

```text
https://your-domain.com/brand.php?id=12
```

در پنل → **گالری برندها**:

1. برند را از فهرست انتخاب کنید.
2. در بخش «اطلاعات صفحه» یک معرفی کوتاه و در صورت نیاز تصویر کاور ثبت کنید.
3. از فرم «افزودن کار یا محتوای جدید» برای هر پروژه یک عنوان، دسته، توضیح و تصویر اضافه کنید.
4. ترتیب نمایش را با فیلد عددی یا دکمه‌های ↑ و ↓ تغییر دهید.
5. هر آیتم را جداگانه پنهان، ویرایش یا حذف کنید.

تصویر هر آیتم را می‌توان از کامپیوتر آپلود کرد یا با آدرس `https://` ثبت کرد. در صفحه عمومی، گالری به شکل یک شبکه ادیتوریال و واکنش‌گرا نمایش داده می‌شود. اگر هنوز برای برندی کاری ثبت نشده باشد، صفحه خالی نمی‌ماند و پیام «در حال تکمیل» نشان می‌دهد.

> این صفحه برای هر برند مستقل است؛ بنابراین نمونه‌کارهای یک کارفرما با نمونه‌کارهای کارفرمای دیگر قاطی نمی‌شود.

## فونت اختصاصی، رنگ و CSS سفارشی

همه این تنظیمات در پنل → **ظاهر، فونت و CSS** قرار دارند.

### آپلود فونت اختصاصی

| مورد | مقدار |
|---|---|
| فرمت‌های مجاز | `woff2` (پیشنهادی)، `woff`، `ttf`، `otf` |
| حداکثر حجم | ۶ مگابایت |
| فونت متن | برای همه متن‌های سایت |
| فونت تیتر | جداگانه و اختیاری؛ اگر خالی بماند، همان فونت متن استفاده می‌شود |

پس از آپلود، فایل در `uploads/fonts/` ذخیره می‌شود و پیش‌نمایش زنده همان‌جا نمایش داده می‌شود.

**نام خانواده فونت** را می‌توانید لاتین و دلخواه بگذارید (مثلاً `NegahCustom`)؛ همین نام در CSS استفاده می‌شود.

اگر فونت شما روی یک سرویس بیرونی میزبانی می‌شود، آدرس فایل CSS آن را در فیلد «آدرس CSS فونت بیرونی» بگذارید.

> آپلود فایل روی سرور خودتان به‌دلیل سرعت و پایداری (به‌ویژه در ایران) توصیه می‌شود.

### رنگ تأکیدی

با انتخابگر رنگ، رنگ اصلی سایت را عوض کنید. این رنگ در دکمه‌ها، اعداد، برچسب‌ها،
خطوط تأکیدی و نوار پیشرفت استفاده می‌شود و نسخه روشن و تیره‌اش به‌صورت خودکار محاسبه می‌شود.

```css
:root { --accent: #0A9F83; }   /* مقدار پیش‌فرض: سبزآبی */
```

### CSS سفارشی

هر کد CSS که می‌خواهید بنویسید، در این کادر بگذارید. کد شما **بعد از** استایل اصلی
بارگذاری می‌شود، پس با آن اولویت دارد. متغیرهای آماده:

```css
var(--accent)      /* رنگ تأکیدی */
var(--accent-dk)   /* نسخه تیره */
var(--paper)       /* پس‌زمینه کاغذی */
var(--ink)         /* رنگ متن اصلی */
var(--muted)       /* رنگ متن کم‌رنگ */
var(--line)        /* رنگ خطوط */
var(--font-body)   /* فونت متن */
var(--font-head)   /* فونت تیتر */
```

نمونه‌های کاربردی:

```css
/* گوشه‌های گرد */
.card, .btn, .wall__cell, .panel { border-radius: 10px; }

/* تیتر درشت‌تر */
.hero__title { font-size: clamp(44px, 7.5vw, 104px); }

/* حذف سیاه‌وسفید شدن لوگوها */
.wall__cell img, .logo-strip__cell img { filter: none; opacity: 1; }
```

اگر نتیجه مطلوب نبود، دکمه **«پاک کردن CSS سفارشی»** همه را برمی‌گرداند.

## تغییر از SQLite به MySQL

اگر ابتدا با SQLite نصب کردید و بعداً خواستید به MySQL منتقل شوید:

1. در cPanel دیتابیس و کاربر MySQL را بسازید
2. در `includes/config.php` مقادیر را وارد کنید:

```php
'driver' => 'mysql',
'mysql'  => [
    'host'    => 'localhost',
    'name'    => 'نام_دیتابیس',
    'user'    => 'نام_کاربر',
    'pass'    => 'رمز_عبور',
    'charset' => 'utf8mb4',
],
```

3. `install.php` را باز کنید و با انتخاب MySQL، نصب را دوباره اجرا کنید
   (این کار جداول و داده‌های پیش‌فرض را می‌سازد؛ لوگوهای آپلودی حذف نمی‌شوند)
4. **`install.php` را دوباره حذف کنید**

## شخصی‌سازی پیشرفته (از داخل کد)

بیشتر تغییرات ظاهری از پنل انجام می‌شود؛ اما اگر می‌خواهید مستقیم در کد دست ببرید:

همه متغیرهای طراحی در ابتدای `assets/css/style.css` تعریف شده‌اند:

```css
:root {
  --paper:   #F6F4EF;   /* پس‌زمینه کاغذی */
  --ink:     #16130F;   /* رنگ متن اصلی */
  --accent:  #0A9F83;   /* رنگ تأکیدی — از پنل هم قابل تغییر است */
  --maxw:    1300px;    /* حداکثر عرض محتوا */
  --gut:     clamp(18px, 4.6vw, 64px);   /* فاصله کناره‌ها */
}
```

> اگر `--accent` را در پنل تغییر دهید، مقدار آن از `assets/css/theme.php` تزریق می‌شود
> و مقدار داخل `style.css` را بازنویسی می‌کند.

فونت پیش‌فرض **وزیرمتن** به‌صورت محلی در `assets/fonts/` میزبانی می‌شود (تک فایل متغیر،
حدود ۱۱۰ کیلوبایت) — بنابراین سایت به CDN خارجی وابسته نیست و در ایران سریع لود می‌شود.
مجوز فونت در `assets/fonts/OFL-Vazirmatn.txt` است.

## امنیت

پیاده‌سازی‌شده در این پروژه:

- رمز عبور با `password_hash` (الگوریتم پیش‌فرض PHP) ذخیره می‌شود
- محافظت **CSRF** روی همه فرم‌های سایت و پنل
- کوکی سشن با `HttpOnly` و `SameSite=Lax`
- بازسازی شناسه سشن پس از ورود موفق
- قفل موقت ورود پس از ۵ تلاش ناموفق
- کوئری‌ها همه با **Prepared Statement** (بدون خطر SQL Injection)
- خروجی‌ها با `htmlspecialchars` (بدون خطر XSS)
- اعتبارسنجی نوع، حجم و سالم بودن فایل‌های آپلودی
- جلوگیری از اجرای کد PHP در پوشه `uploads` با `.htaccess`
- مسدودسازی دسترسی مستقیم به `includes/` و `data/`
- فرم تماس با تله اسپم (honeypot)، محدودیت زمانی و اعتبارسنجی شماره

### توصیه‌های تکمیلی

- بعد از نصب، فایل `install.php` را حذف کنید
- از پوشه `admin` با رمز قوی محافظت کنید
- در `includes/config.php` مقدار `debug` را `false` نگه دارید
- از پنل هاست، گواهی **SSL** را فعال کنید تا سایت با `https` باز شود

## پرسش‌های رایج

**سایت سفید یا خطای ۵۰۰ نشان می‌دهد.**
در `includes/config.php` مقدار `debug` را موقتاً `true` کنید تا پیام خطا را ببینید. رایج‌ترین علت: نبود دسترسی نوشتن روی پوشه `data` یا `uploads`.

**لوگو آپلود نمی‌شود.**
دسترسی پوشه `uploads/logos` باید ۷۵۵ باشد. همچنین حجم فایل باید کمتر از ۲ مگابایت و فرمت آن PNG، JPG، WEBP، GIF یا SVG باشد.

**فونت درست نمایش داده نمی‌شود.**
مطمئن شوید فایل `assets/fonts/Vazirmatn-Variable.woff2` آپلود شده است.

**می‌خواهم چند برند را جابه‌جا کنم.**
از دکمه‌های ↑ ↓ در کنار هر برند استفاده کنید، یا فیلد «ترتیب» را با اعداد کوچک‌تر/بزرگ‌تر تغییر دهید (عدد کمتر = بالاتر).

**صفحه نمونه‌کارها نمایش داده نمی‌شود.**
این بخش فقط زمانی در سایت ظاهر می‌شود که حداقل یک نمونه‌کار فعال ثبت شده باشد — این رفتار عمدی است.

**فونت اختصاصی آپلود کردم ولی سایت تغییر نکرد.**
۱) در پنل → ظاهر، فونت و CSS بررسی کنید که کنار نام فایل برچسب «فعال» باشد.
۲) «نام خانواده فونت» باید پر باشد (اگر مطمئن نیستید `Vazirmatn` بگذارید).
۳) کش مرورگر را با `Ctrl + Shift + R` تازه کنید.

**فقط چند برند در صفحه اصلی می‌بینم.**
این همان حالت «انتخاب دستی» است. برای افزودن بقیه، دکمه ★ کنار هر برند را بزنید؛
یا حالت را در پنل → ظاهر، فونت و CSS روی «اولین موارد فهرست» بگذارید و تعداد را بیشتر کنید.

**انیمیشن‌ها را نمی‌خواهم.**
پنل → ظاهر، فونت و CSS → «انیمیشن‌های سایت» → خاموش.

**منو نمی‌خواهم / می‌خواهم منو برگردد.**
سایت به‌صورت پیش‌فرض **بدون منو** است؛ سربرگ فقط لوگوتایپ برند و شماره تماس را نشان می‌دهد
و پاصفحه سه ستون دارد (برند، تماس، شبکه‌های اجتماعی). اگر بعداً منو لازم شد، بگویید تا اضافه کنم.

**می‌خواهم شماره تماس در سربرگ نباشد.**
شماره را در پنل → «متن‌ها و تماس» خالی بگذارید؛ آن‌وقت فقط لوگوتایپ برند در سربرگ می‌ماند.

**لوگوها سیاه‌وسفید دیده می‌شوند.**
این یک انتخاب طراحی برای یکدست شدن دیوار لوگوهاست و با بردن ماوس روی هر لوگو رنگی می‌شود.
برای رنگی شدن همیشگی این کد را در «CSS سفارشی» بگذارید:

```css
.wall__cell img, .logo-strip__cell img { filter: none; opacity: 1; }
```
